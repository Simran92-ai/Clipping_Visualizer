What is Clipping?

On this page: Algorithms · Advantages · Performance · Line Clipping Lab · Polygon Clipping Lab

Clipping means cutting away the part of a picture that lies outside a chosen rectangle (or other region) so that only the inside part is drawn. Think of looking at a large poster through a window: you can only see what is inside the window frame.

Types / Algorithms

Cohen-Sutherland Line Clipping

Every end point of a line is given a 4-bit region code (Top, Bottom, Right, Left) telling which side of the window it lies on. A bit of 1 means the point is beyond that boundary. Code 0000 means inside the window.

  • Both codes 0000 → line is completely inside (accept).
  • Bitwise AND of the codes ≠ 0000 → both points are on the same outer side, so the line is completely outside (reject).
  • Otherwise → compute the intersection with a window edge, replace the outside point and repeat.

Bit order: Top, Bottom, Right, Left (screen coordinates, y increases downward).

Liang-Barsky Line Clipping

Writes the line as P(t) = P1 + t(P2 − P1), 0 ≤ t ≤ 1, and uses four inequalities (one per window edge) to find the range of t that stays inside. It needs fewer intersection calculations than Cohen-Sutherland and is usually faster.

Sutherland-Hodgman Polygon Clipping

Clips a polygon against one window edge at a time (left, right, top, bottom). For each polygon edge it outputs the end point, the intersection point or both, depending on whether the points are inside or outside. The output of one edge becomes the input of the next. It is used for the buildings, lake and park in the GIS demo and for shapes in the video editor.

Advantages of Clipping

  • Reduces unnecessary rendering
  • Improves performance
  • Displays only required objects
  • Saves processing time
  • Useful in zooming, panning and animation

Performance Considerations

SituationWhy clipping matters
Large mapsThousands of roads and buildings exist, but only those in the viewport need drawing.
High-resolution imagesOnly the visible pixels of a huge image are copied to the screen.
Multiple graphical objectsObjects completely outside are rejected early with cheap tests.
Video framesLayers extending beyond the frame are cut so nothing outside is rendered or exported.
Frequent movement / animationClipping is repeated every frame, so a fast algorithm keeps animation smooth.
