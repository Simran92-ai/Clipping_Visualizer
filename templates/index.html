Introduction

Clipping is the process of removing the parts of a graphical object that lie outside a chosen viewing region (the clipping window) and keeping only the visible part.

Why it is used: a screen can show only a limited area. Drawing everything outside it wastes processing time, so the system first decides what is visible and renders only that.

How it works: each line or polygon is compared with the window boundaries. Objects fully inside are kept, objects fully outside are discarded, and objects crossing the boundary are cut at the edge so only the inside portion remains.

Real applications: map software (GIS), video and photo editors, image viewers, games, CAD tools, window systems and 3D rendering pipelines.
